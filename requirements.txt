# SlaughterMudae — Python dependencies
# ---------------------------------------------------------------------------
# The framework has ZERO hard dependencies: core, plugins, CLI, TUI,
# dashboard (HTTP + WebSocket), SQLite persistence, audit trail and the
# entire test/simulation suite run on the Python standard library.
#
#   python3 -m unittest discover -s tests -t .     # verify: no installs needed
#
# Requires Python >= 3.10 (uses asyncio.Task cancellation semantics,
# match-free stdlib APIs tested on 3.13).
# ---------------------------------------------------------------------------
