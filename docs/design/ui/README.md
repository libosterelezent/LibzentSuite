# LibzentSuite UI Design

In-depth design documents for the LibzentSuite dashboard UI.

Built from docs/design/tokens.json + docs/design/component-specs.md.
Organized by component, one file per component, with exact dimensions,
colors, typography, states, and layout.

## Sections
- Primitives: Button, IconButton, TextInput, SearchField, Checkbox, Switch, Badge, Divider
- Composites: NavigationItem, Card, Section, FormField, Dialog, EmptyState, DataTable
- Domain: AccountIdentity, AccountStatus, PluginAssignment, PresetSelector, ActivityEntry, BulkActionToolbar
