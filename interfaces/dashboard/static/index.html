Advanced

Import .env credentials

one-shot copy of the legacy DISCORD_TOKEN_* .env entries of registered accounts into ENCRYPTED database storage. Accounts that already have a stored credential are skipped unless "overwrite" is checked. The report shows account names only — never values.

Global emergency stop

cancels every task and stops every account NOW — the framework halts. Use when anything looks wrong.

Graceful shutdown

drains the scheduler, stops all accounts, closes the database. The dashboard stops responding afterwards.

Dashboard token

stored locally (safe-storage fallback when localStorage is blocked). A token in the URL (?token=…) seeds it and is cleaned from the address bar.
